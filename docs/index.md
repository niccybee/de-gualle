## A foundation you can read.

```html
<link rel="stylesheet" href="/css/de-gualle.css" />

<main>
  <h1>A fresh start.</h1>
  <form>
    <label for="email">Email address</label>
    <input id="email" name="email" type="email" required />
    <button type="submit">Keep me in the loop</button>
  </form>
</main>
```

No class vocabulary to memorise. No component JavaScript to ship. Just a small, documented system of native elements and purposeful compositions.
